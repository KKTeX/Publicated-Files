# チャッピーと東大国語の解答用紙の再現作成&採点

Qiita 記事用の公開ファイルです。ChatGPT（Work）が Scoring64 のプラグインで、見本と同じ形の 3 ページの解答用紙を組み、手書き風の答案 2 人分を採点して返却用 PDF を作るまでの、プロンプトと材料をまとめています。

**非公式**です。東京大学とは関係ありません。`用紙見本.pdf` は Scoring64 で組んだ再現で、大学名・年度・ロゴは入れていません。実際の試験問題・受験者情報は含みません（答案の氏名と解答は実演用の作り物です）。

GitHub上の公開先: <https://github.com/KKTeX/Publicated-Files/tree/main/Qiita/チャッピーと東大国語の解答用紙の再現作成&採点>

- `qiita-todai-kokugo-scoring64.md`: 記事の原稿
- `プロンプト.txt`: ChatGPT に送ったプロンプト全文
- `修正プロンプト.txt`: 仕上がりを見て直させた 2 回目のプロンプト（記事の追記）
- `ChatGPT実行記録.md`: 2 回のプロンプトの履歴、使ったモデル・アプリのバージョン、かかった時間、ChatGPT の報告
- `用紙見本.pdf`: 見本の用紙（A4 横・3 ページ）。作業フォルダに入れて使う
- `手書き答案.swift`: 発行した印刷用 PDF に手書き風の答案を書き込み、スキャン風の答案 PDF にするスクリプト。作業フォルダに入れて使う
- `解答例.json`: `手書き答案.swift` に渡す解答の例（2 人分）
- `figures/`: 記事の画像と実演動画 `demo.mp4`（16:9・約 44 秒・無音。1 回目だけを撮ったもの）。`fix-marks.png` と `fix-mae.png` は 2 回目で直す前と直したあと

## 手書き答案.swift

macOS の標準フレームワーク（PDFKit・CoreGraphics・CoreText・ImageIO・CoreImage）だけで動きます。`swift` コマンド（Xcode または Command Line Tools）が必要です。

```sh
swift 手書き答案.swift --fields
swift 手書き答案.swift 発行PDF.pdf 解答例.json 出力フォルダ
```

1 行目は解答欄の一覧（ラベル・ページ・種類・字数）を表示します。2 行目は、Scoring64 で発行した印刷用 PDF（1 人 3 ページ × 人数）に解答を書き込み、`出力フォルダ/答案_01.pdf`、`答案_02.pdf` … を書き出します。QR コードはそのまま残し、読めることを確かめます。字は Klee、なければ教科書体、ヒラギノ明朝の順に使います。オプションと JSON の形式はファイルの冒頭にあります。

解答欄の位置は `用紙見本.pdf` の罫線から埋め込んであるので、この見本と同じ形の用紙にだけ使えます。
